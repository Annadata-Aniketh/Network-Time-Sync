# Project documents

TimeSync is Project 23, Team 11, Section K. Use the repository's `final` branch
for the documented implementation and demo.

| File | Purpose |
| --- | --- |
| [Presentation](TimeSync%20-%20Project%2023.pdf) | 17-slide presentation updated for the final security and load checks. |

The performance results in the presentation and report describe the recorded
experiments from 1 November 2026. The presentation also includes the final
validation. The academic report is an earlier snapshot; see the final
verification for the current code and test counts. The browser lab illustrates the clock
mechanism; its animations are not new Mininet measurements.

The supplied command sheet used `--branch main`. Its repository edition uses
`--branch final`, matching the launcher instructions and academic report.
The original files in Downloads have not been modified. The editable presentation
is also available as [PowerPoint](TimeSync%20-%20Project%2023.pptx).

See [testing instructions](TESTING.md) and the [security scope](../SECURITY.md)
for development checks and supported use.
